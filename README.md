# Violet Arcade

A small, offline-ready browser arcade with five games: Neon Snake, Afterglow Pong, Memory Matrix, Reaction Rush, and Violet 2048.

## Run it on Windows

1. Double-click `start-local.bat`.
2. The page opens at [http://127.0.0.1:4173](http://127.0.0.1:4173).
3. Enter a player name. Add another handle from **Manage players** when someone else wants a turn.
4. Double-click `stop-local.bat` when you are finished.

The launcher uses the PowerShell included with Windows. The page has no external assets or network dependencies. Player profiles, personal bests, and recent runs are stored in this browser on this device.

## Controls

- **Neon Snake:** arrow keys or WASD; Space pauses. Touch direction buttons are available on smaller screens.
- **Afterglow Pong:** W/S or ↑/↓. First to five wins against the house.
- **Memory Matrix:** click or tap two cards at a time.
- **Reaction Rush:** start the 20-second sprint, then click or tap the target.
- **Violet 2048:** arrow keys or WASD; touch direction buttons are available on smaller screens.
